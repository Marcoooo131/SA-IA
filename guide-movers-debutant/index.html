Le principe

Un client déménage : 3 issues possibles

Ton rôle : comprendre ce que veut le client, puis lancer le bon circuit dans le CRM. Tout part toujours d'un case « Movers – Déménagement ».

Moving OUT

Le client emmène son alarme dans son nouveau logement.

  • Work Order Installation (réinstallation)
  • Booking d'un technicien à la nouvelle adresse

Moving IN · Takeover

Le nouvel occupant reprend l'alarme déjà en place.

  • Création d'un Lead « Moving In Repreneur »
  • Transmis à un commercial

Résiliation

Personne ne garde le système : on récupère le matériel.

  • Work Order Termination
  • Booking pour démontage / récupération
💡
Un même dossier peut combiner deux issues : par exemple le client part avec son alarme (Moving Out) et le nouvel occupant est intéressé (Takeover).

Module 1 · Téléphonie

Se connecter et préparer son casque

  1. Ouvre la Landing Page Sector Alarm et clique sur la tuile Twilio Flex (« Log on our contact center »).
  2. Au chargement tu es en statut Offline. À droite, l'onglet Stats montre la file Voice – FR Movers (appels en cours, en attente, agents connectés).
  3. Clique sur l'icône casque 🎧 en haut et vérifie le périphérique de sortie et le micro : sélectionne ton casque (pas les haut-parleurs du PC).
  4. Change ton statut via le menu en haut à droite selon ce que tu fais (voir ci-dessous).

Les statuts

Available tu reçois les appels entrants · Outbound Calls tu passes des appels sortants · Wrap Up fin d'appel (tâche à clôturer) · Offline déconnecté

Module 1 · Téléphonie

Passer un appel sortant et le gérer

  1. Passe en Outbound Calls, ouvre le pavé Call et saisis le numéro au format international : +33 6 xx xx xx xx. Lance l'appel.
  2. L'écran affiche Connecting call, ton numéro d'appelant et la file FR Movers.
  3. Une fois décroché (Live), clique sur Start Recording si l'appel doit être enregistré.
  4. À droite, Look up contact in CRM : recherche par nom, adresse d'installation ou n° de compte CRM.

Pendant l'appel (barre du bas)

  • 🎙️ Muet
  • ⏸️ Mise en attente (bouton pause du correspondant) — reprends avec le même bouton
  • ↪️ Transfert : onglets Agents, Queues ou External
  • ➕ Ajouter un participant · ⌨️ Pavé numérique
  • 🔴 Raccrocher (ou Hang Up)
⚠️
Après avoir raccroché tu passes en Wrap Up : clique sur Complete pour clôturer, puis remets-toi en Available (ou Outbound Calls). Sinon tu ne reçois plus rien.
Module 2 · CRM

Créer une tâche « PRIO – Movers – Déménagement »

Quand un client signale un déménagement et que le dossier doit être traité ou rappelé, on crée une tâche depuis sa fiche et on la met dans la file Movers.

  1. Ouvre la fiche client (Account), descends à Activities et clique sur l'icône Tâche (calendrier) pour en créer une.
  2. Subject : PRIO – Movers – Déménagement.
  3. Description : colle le modèle ci-contre et complète chaque ligne.
  4. SAVE, puis menu … → Add to Queue → file Movers → Add.
  5. Vérifie : la tâche apparaît dans CS – Movers Prio task sur le dashboard.
Nom interlocuteur : Numéro de téléphone : Propriétaire / locataire : Nouvelle adresse : Date de Déménagement : Horaire de Rappel : Informations Complémentaires :
✍️
Exemple de « Informations complémentaires » : « Le client veut désinstaller le système car bailleur social », « rappeler après 14h ».
Module 3 · CRM

Créer le case « Movers – Déménagement »

  1. Sur la fiche client, section Cases → bouton +. Un « New Case » s'ouvre.
  2. Étape Register Data : renseigne Title, vérifie Account, choisis l'Installation, le Mover Type, le Contract et le Case Type.
  3. Clique sur Next Stage → tu passes à l'étape Info (barre verte).
  4. Réponds à Moving Out Or Moving In ? → Out (le client part avec son alarme) ou In (repreneur).
  5. Le formulaire affiche alors les champs du parcours choisi. SAVE régulièrement.

Module 4 · Réinstallation

Moving Out : le client emmène son alarme

  1. Étape Info : Moving Out Or Moving In = Out.
  2. Remplis la nouvelle adresse : Street 1 (New Address Moving Out), Postal Code, City, puis la Moving Out Date. Le champ Coverage indique si la zone est couverte (ex. Full service).
  3. À droite, vérifie le bloc Contract Information : bon contrat, conditions, Last Income Date (Moving Out), Case Category = Moving Customer, Case Reason = Moves to new adress.
  4. Moving Out interested in Installation = Yes si le client veut réinstaller.
  5. Completed Move Out Info = Yes, puis clique sur Finish.
⚙️
Au Finish, le CRM crée automatiquement une Opportunity « Takeover New Sale » et un Work Order Installation (« WO – Mover », file Movers). Tu le retrouves dans le bloc Work Orders (Case) du case.
Module 4 · Réinstallation

Préparer le Work Order « WO – Mover »

  1. Ouvre le WO depuis le case. Vérifie Type of Work Order = Installation et Work Order Template = Mover M.
  2. Contrôle la centrale avec SITEADMIN (sur la fiche client) : bon n° de panel, bonne adresse.
  3. Section Work Order Products → + : ajoute le pack à réinstaller et le produit de contrat Maintenance et télésurveillance. Vérifie les prix dans la fenêtre produit, puis SAVE & CLOSE.
  4. Section Service Codes : le code de réinstallation (ex. Réinstallation SAS M) doit être présent.
  5. Complète la Description du WO (modèle ci-contre).
Mover vendu par : Ancien HWID : Système : SAS Type de contrat : Home Contacter TST pour reprise centrale si SAS Documents : Contrat / Mandat SEPA / Cerfa (uniquement pour les particuliers) Matériel : (ex. 1x DOC, 2x Sirène intérieure…) Complément d'installation :
💡
Le Total Hardware Price et le Total Contract Price se calculent tout seuls à partir des produits ajoutés : relis-les avant le booking.
Module 5 · Booking

Réserver le créneau du technicien

  1. Descends à Booking and Product Information.
  2. Timeband : All/Half day. Booked Start Date / Booked End Date : la période dans laquelle chercher (ex. du jour J à J+7).
  3. Vérifie l'adresse d'intervention (à droite) et le Mobile Phone for confirmation.
  4. Clique sur Get appointments, choisis un créneau avec le client et valide.
  5. Si un message dit que le compte a déjà un WO ouvert ou planifié, lis-le puis OK pour continuer.
  6. Résultat attendu : « Work order is booked », Status Reason = Scheduled, dates en haut à droite.

Les messages à connaître

  • Work order is booked → c'est bon ✅ (boutons Cancel booking / Re-schedule booking disponibles).
  • ERROR (code: 8) An appointment for the criteria supplied is not available → aucun créneau sur la période : élargis les dates, sinon No Cap.
  • ERROR (code: 280) Reserved → créneau indisponible : réessaie, sinon No Cap.
  • Pending email warning à l'ouverture → Close, sans impact.
Module 5 · Booking

Confirmer le rendez-vous au client

📱 SMS

Après le booking, un SMS de confirmation part au client (date + créneau). Tu le vois dans le case, onglet Notes → Activities. Vérifie qu'il y est.

✉️ Email récapitulatif

  1. Depuis le case : nouvel email, From = Movers.
  2. INSERT TEMPLATE → Sector Alarm – Récapitulatif concernant votre déménagement.
  3. Remplace tous les champs surlignés en jaune.
  4. SEND.

Champs à compléter dans l'email

Jour de l'intervention · Créneau d'arrivée du technicien · Durée de l'intervention · Électricité sur place · Réseau (GSM / Wifi) · Travaux prévus · Matériel à réinstaller.

⚠️
Rappelle au client que le titulaire du contrat doit être présent le jour de la réinstallation et qu'un rendez-vous non honoré est facturé 89 € (c'est écrit dans l'email). Si le CRM affiche « At least one recipient does not have an email address », ajoute ou corrige l'email sur la fiche avant d'envoyer.
Module 6 · Moving In

Takeover : le nouvel occupant reprend l'alarme

  1. Dans le case (Case Type Takeover), étape Info : Moving Out Or Moving In = In. New house owner interested : Yes / Unknown.
  2. Remplis le bloc repreneur : Is business? (Moving In), First Name, Last Name (ou Business Name si professionnel), Mobile phone, E-mail address, Product Line (ex. Smart Alarm System).
  3. Completed Move In Information = Yes → SAVE → Finish.
  4. Le CRM crée un Lead : Topic « Moving In Repreneur », Type of Lead / Lead Source = Moving In, Sales Type = Movers.
  5. Sur le Lead : complète la Workorder Description (ex. « le client veut reprendre le contrat pour le 19/10 »), vérifie Contract Terms, puis attribue le Owner / Sales Person au commercial qui reprend le dossier. SAVE.
💡
Le Takeover concerne le nouvel occupant. L'ancien client (celui qui part) reste sur son propre parcours : réinstallation (Module 4) ou résiliation (Module 7).
Module 7 · Résiliation

Résiliation : créer le Work Order « Termination »

  1. Depuis le case, bouton WORK ORDER → nouveau WO de type Termination. Account, Contract, Installation et Case sont pré-remplis. SAVE.
  2. Work Order Template : Termination WO – Mover – Déménagement. Le Subject et la Description se remplissent tout seuls.
  3. Complète dans la Description le nom du client et le numéro de téléphone.
  4. Vérifie dans Work Order Products la ligne Service de résiliation (0,00 €).
  5. Fais le booking comme au Module 5 (Get appointments) → statut Scheduled.

Ce que le modèle met dans la Description :

Déménagement BILLING : Pas de remboursement, pas de facturation Nom du client : Numéro de téléphone : Merci de laisser le clavier et prendre des stickers Takeover et de coller sur le clavier Système : SAS Démontage et récupération du système : Oui Récupérer plaques et stickers Récupérer carte SIM et contact TST pour reset
Module 8 · No Cap

Pas de créneau ? Demande au planning (No Cap)

Si Get appointments renvoie une erreur (code 8, code 280…) même en élargissant les dates, ne bloque pas le client : le planning peut forcer un créneau.

  1. Dans le WO, copie l'Activity Number (FR-xxxxxxx).
  2. Ouvre Teams → canal MO TO/Planning et No Cap.
  3. Poste un message au format : FR – Nom du client – Code postal – Disponibilités (plusieurs dates si possible).
  4. Ajoute une contrainte utile si besoin (ex. « pas trop tôt le matin », « dispo tous les mardis »).
  5. Suis la réponse du planning dans le fil et confirme au client une fois le créneau posé.
FR-XXXXXXX - Nom du client - Code postal - dispos : JJ/MM, JJ/MM, JJ/MM

Exemples (fictifs) :

FR-1234567 - Jean Martin - 29000 - dispos : 7/12, 14/12, 17/12 FR-7654321 - Claire Robert - 72000 - dispo tous les mardis, merci de booker le premier mardi possible
⚠️
Un message = un dossier. Toujours le numéro FR en premier : c'est ce que le planning cherche dans le CRM.
À éviter

Les pièges du débutant

🔁 Statut Twilio oublié

Après un appel, toujours Complete le wrap-up et repasser en Available.

📭 Tâche hors file

Une tâche PRIO non ajoutée à la file Movers est invisible pour l'équipe. Vérifie le dashboard.

⏭️ Finish trop tôt

Ne clique sur Finish qu'après avoir mis Completed Move Out/In Info = Yes et tout vérifié : c'est ce qui crée WO / Lead.

💸 Produits non vérifiés

Relis les produits et les totaux du WO avant le booking.

✉️ Pas de récap

Chaque réinstallation bookée = SMS vérifié + email récapitulatif envoyé.

🧩 No Cap incomplet

Sans n° FR, code postal et disponibilités, le planning ne peut rien faire.
