# Guide Movers — débutant

Présentation web pas à pas pour les nouveaux agents du service Movers, réalisée à partir des vidéos
d'aide internes : Twilio Flex, tâche « PRIO – Movers – Déménagement », case « Movers – Déménagement »,
réinstallation (Moving Out / WO Installation), takeover (Moving In / Lead), résiliation (WO Termination),
booking, confirmation au client et procédure No Cap.

Page statique (un seul fichier `index.html`, sans build ni dépendance). Navigation au clavier (← →),
par glissement sur mobile ou via le sommaire. Modèles de texte copiables en un clic. Aucune donnée
client : les exemples sont fictifs.

En ligne : `https://<compte>.github.io/SA-IA/guide-movers/`
