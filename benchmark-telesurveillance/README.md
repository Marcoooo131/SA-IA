# Benchmark concurrentiel – Télésurveillance

Slide unique (16:9, 1920 × 1080) comparant les offres de télésurveillance : homiris (Confort / Sérénité), Nexecur (Initiale / Intégrale), une offre à 40 €/mois et IMA Protect (À la carte / Tout inclus).

## Utilisation

- Ouvrir `index.html` dans un navigateur (aucune installation, aucune dépendance hormis les polices Google Fonts).
- La slide s'adapte à la taille de l'écran ou du vidéoprojecteur.
- Boutons en bas à droite (au survol) : **Sources** (captures d'origine), **Plein écran**, **Exporter en PDF** (ouvre l'impression → « Enregistrer au format PDF »).

## Contenu

- `index.html` : la slide, autonome (HTML + CSS + un petit script de mise à l'échelle).
- `assets/` : les 4 captures sources.

Les données reprennent uniquement les captures : aucun tarif ni aucune prestation ajoutés.
