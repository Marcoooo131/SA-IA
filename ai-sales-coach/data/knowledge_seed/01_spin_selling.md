Le modèle SPIN distingue quatre types de questions utilisées dans les ventes complexes :

- Situation : comprendre le contexte (« Où se situe votre futur logement ? »). Utiles mais à limiter : trop de questions de situation lassent le client.
- Problème : faire émerger les difficultés ou insatisfactions (« Qu'est-ce qui vous inquiète dans ce nouveau quartier ? »).
- Implication : explorer les conséquences du problème (« Si vous vous absentez souvent, que se passe-t-il pour la maison pendant ce temps ? »).
- Need-payoff (besoin / bénéfice) : amener le client à formuler lui-même la valeur d'une solution (« Qu'est-ce que ça changerait pour vous d'être prévenu immédiatement ? »).

Application rétention déménagement : la demande de résiliation n'est pas le « problème » ; le problème est souvent un manque d'information (le client ignore que le service peut le suivre) ou un besoin nouveau (nouveau logement plus exposé). Les questions d'implication et de bénéfice aident le client à reconsidérer sa décision par lui-même, plutôt que sous la pression.
